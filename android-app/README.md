# Android-приложение «Что приготовить?»

Оболочка (Capacitor) вокруг сайта https://olga113q.github.io/Eatsss/recipes-app/ — всё содержимое
грузится с сайта, поэтому обновления сайта сразу видны в приложении, переустанавливать не нужно.
Без интернета работает за счёт офлайн-режима сайта (после первого запуска).

Скачать APK: https://github.com/Olga113q/Eatsss/releases/download/android/chto-prigotovit.apk

APK собирается автоматически (`.github/workflows/android.yml`) при изменениях в этой папке
или вручную (Actions → Android APK → Run workflow). Номер версии растёт с каждой сборкой,
подпись всегда одним ключом (`keystore/debug.keystore`) — новая сборка ставится поверх старой
без потери данных. Ключ лежит в открытом репозитории: для личного приложения это нормально,
но при публикации в магазине его нужно заменить на секретный.
