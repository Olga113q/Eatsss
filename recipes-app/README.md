# Что приготовить? — подбор рецептов по продуктам

Личный сайт по типу Supercook: отмечаете продукты, которые есть дома, и видите,
какие блюда из них можно приготовить и чего не хватает.

- ~7 000 рецептов на русском (выгрузка с eda.ru), с ингредиентами, шагами,
  временем и калорийностью;
- ~570 продуктов: разные названия сведены к одному («Куриное филе»,
  «Окорочка», «Цыпленок» → «Курица»);
- фильтры: тип блюда, кухня, время, сколько продуктов может не хватать;
- избранное и список покупок (недостающее из рецепта добавляется одной кнопкой);
- всё хранится в браузере, сервер не нужен.

## Как открыть

Просто откройте `index.html` в браузере (двойной клик). Интернет не нужен,
кроме ссылки «Открыть на eda.ru».

## Как устроено

```
index.html, app.js, style.css   — сам сайт
data/recipes.js                 — база рецептов (генерируется)
tools/build_data.py             — сборка базы из SQL-дампа
tools/normalize.py              — правила «название ингредиента → продукт»
tools/sqldump.py                — разбор SQL-дампа
```

## Пересборка базы

Нужен Python 3. Источник — дамп из репозитория
https://github.com/Maximilyanus29/recipes:

```bash
git clone --depth 1 https://github.com/Maximilyanus29/recipes.git /tmp/eda
python3 tools/build_data.py /tmp/eda/docker/docker-entrypoint-initdb.d/recipes.sql
```

Если какой-то ингредиент попал не в тот продукт, поправьте или добавьте правило в
`tools/normalize.py` (правила проверяются сверху вниз, срабатывает первое
подходящее) и пересоберите базу.

Рецепты взяты с eda.ru и используются только в личных целях — сайт не стоит
выкладывать в открытый доступ.
